# stubsmith

One-command typing-hygiene audit of your dependency tree, with ready-to-run fixes

## Installation

=== "pip"

    ```bash
    pip install stubsmith
    ```

=== "uv"

    ```bash
    uv add stubsmith
    ```

## Quick Example

```python
from stubsmith import add

result = add(1, 2)
print(result)  # 3
```
